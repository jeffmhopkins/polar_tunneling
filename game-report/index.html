How to read this

Every model was trained on 2025 pitches only, so nothing it says about this game comes from 2026 results. Each candidate pitch is represented by the same real 2026 pitches from that pitcher (his actual shapes and locations), placed into the count after the previous pitch, against an average hitter. CSW means a called strike or a whiff.

One game is a few hundred pitches, so its numbers mostly show what each picker does, not which is best. The season comparison at the top, over all 2026 pitches, is the evidence. It is observational: pitchers choose with knowledge of the hitter, the catcher and the game plan that these models don't have.
